# 播放器拟真交互改进记录

记录日期：2026-10-14。用户理念：操作拟真的音乐播放器。

## 设计原则

让用户从物体本身理解操作，并在动手时感到明确的因果反馈。唱臂控制播放、转动唱片调整进度已经符合这一方向；中央标签承担左右切歌、上滑队列、下滑收藏、长按歌单五种操作，需要减轻记忆负担。

这里保留基于截图和代码提出的完整建议，以及随后按模拟器体验反馈完成的迭代。第一轮实现前三项，其余方向与实现状态继续保留，不能在后续精简上下文时丢失。

界面名称现统一为「播放列表」，保留唱片架造型与唱片套的物体隐喻。

顶部软件名已统一为「Tacto」。按用户反馈，播放列表只通过右上方的定位图标手动居中定位当前歌曲，并以暖金色短暂高亮约 2 秒后淡出；打开列表或切换当前歌曲时不会自动定位。当前歌曲的常规标记保留，定位不会重新播放歌曲。

## 第一轮：用户已确认实施

实现记录：唱机下方增加可点按的木质播放列表与独立「选歌单」入口；唱臂增加抓取阴影、落针/归位吸附与取消复原；左右拨动增加真实队列相邻封面预览、阈值提示和每方向一次的触觉反馈。操作说明与练习唱片已同步更新。

交互反馈修复：唱臂慢速拖动会被外层页面横滑或纵向滚动先识别。唱臂改为按下时独占命中的触摸，直到松手或取消；命中区域沿实际弯折的唱臂与唱头计算，空白区域继续用于页面导航和滚动。回归测试覆盖真实首页中的慢速拖动、落针、归位以及空白区域导航。已在当前 iPhone 16 Pro 模拟器中验证唱臂横向拖动、落针播放与归位暂停，页面未切换或滚动。

点按手感调整：唱臂仍在按下时接管触摸，抓取视觉与拖动判定延迟 260 毫秒。短按期间不抬针、不显示抓取提示，松手只切换播放/暂停；按住到抬起后再拖动。按住但未拖动时松手恢复原位，快速划动后提前松手也不改变播放。松手、取消、忙碌或组件销毁均清理待触发的抓取计时。

吸附判定与显示调整：播放吸附只要求实际绘制的唱针进入圆形唱片范围，不再要求接近某个播放角度。松手播放，拖回唱片外则取消；支架归位暂停保持原有规则。隐藏唱片与支架的判定圈及唱头周围的圆形标记，保留抓取阴影与文字状态提示。260 毫秒按住判定、触摸接管与取消复原逻辑保持。

### 1. 播放列表实体入口

- 在唱机旁提供露出的唱片套与播放列表，点按打开当前播放队列。
- 提供明确的选歌单入口，保留中央标签长按选歌单、上滑打开队列的快捷操作。
- 首次使用能看到可操作的对象；熟悉后仍可使用快捷手势。
- 空播放列表也能打开，并能继续选择歌单。
- 对象职责：唱臂负责播放/暂停；外圈负责进度；中央标签负责左右换曲；播放列表负责队列与选歌单。收藏对象的独立入口留待后续。

### 2. 唱臂抓取、移动与吸附

- 按住唱头时，唱头轻微抬起，阴影拉开，表示已抓住。
- 拖动时紧跟手指；接近唱片或支架时轻微吸附。
- 吸附、松手落针/归位时给出明确的触觉反馈。
- 未达到落针/归位位置就松手，回到原状态，避免意外播放或暂停。
- 保留轻点唱臂播放/暂停的便捷操作。
- 尊重系统减少动态效果设置；触觉手感需真机验收。

### 3. 换曲封面预览与阈值反馈

- 从中央标签左右拨动时，从对应一侧露出相邻歌曲的封面与标题。
- 达到切换阈值时触觉提示一次，不能因手抖在阈值附近反复振动。
- 左右切歌阈值按用户反馈由 48 增至 56 逻辑像素；预览的完成状态、触觉、泡泡效果和松手切歌使用同一阈值。
- 达到切换阈值后，歌曲预览卡片用非线性曲线轻轻鼓起：约 300 毫秒放大 5%，略微越过后回落，如泡泡膨胀。保持在阈值外不重复播放；拖回阈值内约 180 毫秒恢复原尺寸。首尾不可切换时不鼓起，减少动态效果时关闭此动画。
- 未达到阈值松手，唱片回弹；达到后松手，完成切换。
- 拖回阈值以内或取消手势均不能切歌。
- 队列首尾反馈“第一张了”/“最后一张了”，阻力原因明确，不能伪装成可切换。
- 抬针、换片、落针的完整换片动画作为后续增强；动画应与加载同时进行，不能额外延迟出声。

## 后续建议：完整保留

上一轮继续实现了第 4–8 项的基础体验，以下同步记录用户反馈后的调整：

- 外圈按下时唱片停转，播放中的声音短暂淡出并暂停；定位或取消后恢复之前的状态与音量，原先暂停时不自动播放。系统暂停、切歌与中断优先于手势的自动恢复。
- 进度浮层显示目标时间与正负调整量，一圈仍为 60 秒；总时长按用户反馈由玻璃泡泡改为木面刻字与细线纹样，数字改为白色以提高可读性，保留凹刻质感。
- 播放列表旁增加唱片套的收藏标记，点击打开现有收藏面板。
- 首页曾增加「找音乐」目录与「设置」铭牌；现按用户要求移除这两个可发现入口，搜索和设置继续通过原有侧滑进入。
- 曾增加渐进的情境教学提示；现按用户要求移除自动教学文字、唱臂浮层和切歌卡片提示。保留唱臂抬起、卡片鼓起、触觉与必要进度信息，完整练习教程仍可主动打开。
- 换曲、落针、抬针、定位分别显示对应状态，音乐加载显示等待；操作失败提供对应重试入口。
- 唱机曾按屏幕可用高度缩小；现保留原有尺寸，由可用宽度决定（最大 460）。按用户要求将页面改为固定单屏：缩小顶部留白、播放列表封面和辅助字号，歌曲名与作者使用固定区域；进度和错误重试共享一行，不增加页面高度。播放器主页面取消上下滚动，宽屏时将其余控件放在唱机旁，歌单、搜索和教程面板仍可正常滚动。

尚待探索的增强仍保留：完整抬针/换片/落针动画，以及慢转低灵敏度精调。当前没有额外等待动画结束才出声，也没有改变旋转灵敏度。

### 4. 转动唱片时视听一致

当前触摸唱片后视觉停止旋转，进度在松手后提交。需检查音乐是否仍持续播放，避免用户无法理解是在按住唱片还是只调整进度。

建议行为：按住外圈 → 唱片停转，声音短暂淡出 → 转动预览目标时间 → 松手定位，恢复操作前的播放状态。暂停中调整进度不能自动开始播放。

- 时间提示同时显示目标与差值，例如“目标 1:42 · +12 秒”。
- 一圈调整 60 秒保留为默认值。
- 慢转低灵敏度的精调可探索，但需验证快慢转换的可预测性。

### 5. 收藏操作的物体入口

唱片套上的收藏标记可点按，或将唱片拖入收藏位置。中央标签下滑可作为快捷方式。此项进一步减轻中央标签的操作负担，第一轮不改变现有收藏流程。

### 6. 搜索与设置的可发现入口

用户已要求取消本项新增入口。以下原始建议保留作设计记录，当前实现仍为首页唱片外的左右侧滑。

现有唱片外空白区域左右滑动用于导航，唱片内左右滑动用于换曲，动作相近而功能不同。

- 两侧露出一点房间里的对象：唱片目录对应“找音乐”，机身铭牌或调节区域对应“设置”。
- 支持点按进入，保留左右滑动作为快捷方式。

### 7. 教学按情境出现

用户已要求取消操作时自动出现的教学提示；当前保留主动打开的操作说明与练习教程。以下原始建议继续保留作设计记录。

项目已有可练习的教程。首次只引导完成“选一首歌 → 放下唱针 → 听到音乐”，随后按情境渐进提示：

- 第一次触摸外圈：“沿沟槽转动，调整进度”。
- 第一次拨动标签：“松手换下一张”。
- 第一次打开播放列表：提示如何切换歌单。
- 成功操作后减少提示；完整教程继续保留在操作说明中。

### 8. 状态反馈准确且可恢复

多个操作共用“正在取出唱片”的忙碌文案，建议按操作区分：

- 换曲：“正在取出唱片”。
- 定位：“正在定位 · 1:42”。
- 缓冲：“等待音乐加载”。
- 失败：“这张唱片暂时无法播放 · 点按重试”。

拟真语言负责氛围，具体说明帮助用户理解和恢复操作。

## 验收重点

- 播放列表与选歌单入口无需先阅读教程也能发现；空队列、加载中均有明确状态。
- 唱臂轻点、拖动落针、拖动归位、未到位松手、取消操作均正确。
- 换曲预览与实际上一曲/下一曲一致，不越过队列边界。
- 阈值前松手、越过后拖回、方向反转、取消手势均不会误切歌。
- 小屏幕、大字体、减少动态效果和屏幕阅读器可用。
- 真实触觉和播放过程需要真机确认，组件测试不能替代手感验收。
